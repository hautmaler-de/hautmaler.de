# Die Hautmaler

Statische Website für das Tattoo-Studio in Ottobrunn. Nur HTML, CSS und ein kleines JavaScript fürs mobile Menü. Bleibt dadurch schnell, günstig und leicht zu pflegen.

## Veröffentlichung

Ein Push auf `main` startet `.github/workflows/pages.yml` und veröffentlicht die Website über GitHub Pages.

## Vor dem öffentlichen Start

- [ ] Impressum mit echtem Vor- und Nachnamen des Betreibers ausfüllen (§ 5 TMG, § 18 Abs. 2 MStV verlangen den vollen Namen, nicht nur "Phil").
- [ ] Datenschutzerklärung auf die tatsächlich verwendete Mail-Infrastruktur abstimmen.
- [ ] Prüfen, ob `phil@hautmaler.de` als Postfach eingerichtet ist.
- [ ] DNS für `hautmaler.de` (und optional `www.hautmaler.de`) auf GitHub Pages zeigen lassen.
- [ ] Adresse, Telefonnummer und Öffnungszeiten gegen die aktuellen Angaben auf Instagram/Facebook gegenchecken, falls sich was ändert.
